# TEOS — Греческий йогурт. Concept

Неофициальный дизайн-концепт промо-сайта греческого йогурта TEOS. Автор — Илларион Ершов.

**Unofficial concept. Not affiliated with TEOS.** Сайт некоммерческий и не связан с брендом TEOS и ОАО «Савушкин продукт». Товарный знак и упаковка принадлежат правообладателю.

Статический сайт без сборки: открывается `index.html` (ES-модули, GSAP + ScrollTrigger + Lenis лежат в `vendor/`, собственный WebGL). Для локального просмотра нужен любой статический сервер, например `python3 -m http.server` в этой папке.

Публикуется через GitHub Pages из корня ветки `main`.
